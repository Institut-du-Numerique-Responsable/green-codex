# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the maintainers privately
through the repository's GitHub security reporting feature. Include the affected file, a concise
description, reproduction steps, and the potential impact.

We will acknowledge a report within 14 days and coordinate a fix and disclosure timeline with the
reporter. Do not include secrets or personal data in the report.

## Scope

This project contains instructions and documentation for coding assistants. Reports about prompt
injection, unsafe recommendations, dependency compromise, or accidental disclosure of sensitive
data are in scope. General questions and rule improvements belong in a normal issue.
