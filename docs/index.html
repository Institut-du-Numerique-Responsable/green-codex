Open guidance for sustainable software

Build less. Measure what matters.

Green Codex brings Green IT, accessibility and responsible AI practices into the coding workflow. It gives Codex evidence-based rules for designing, implementing, reviewing and auditing digital services.

View the repositoryInstall the skill

One skill, four reference frameworks

RGESN

Environmental design of digital services, from user need to infrastructure and lifecycle.

GR491

Responsible design decisions across UX, frontend, backend, data, hosting and governance.

Opquast

Reliable, understandable and robust web experiences that complement environmental checks.

RGAA

Keyboard, focus, semantics, contrast, language and assistive technology checks.

Use it in any project

  • Audit a codebase or architecture with cited evidence.
  • Review a pull request for environmental and accessibility risks.
  • Choose measurable, reversible improvements without sacrificing resilience.
  • Keep official acronyms and references intact.

Open and reusable

The skill is MIT licensed for code and CC BY 4.0 licensed for rules and documentation. Contributions and translations are welcome through pull requests.
