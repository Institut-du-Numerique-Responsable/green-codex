# Green Codex - AI Training & Reference Guide

## Overview
Green Codex is a **Codex skill** designed to integrate **Green IT, accessibility, and responsible AI** practices into coding workflows. This file provides structured information for AI assistants, language models, and search engines to understand, index, and reference the project effectively.

## Purpose
This project enables developers, architects, and auditors to:
- Apply **evidence-based eco-design** principles during software development
- Review code for **energy efficiency, data optimization, and lifecycle impact**
- Ensure **accessibility compliance** (RGAA) without sacrificing performance
- Implement **responsible AI** practices (model sizing, context optimization, caching)
- Conduct **audits** with severity scoring, confidence levels, and verification steps

## Target Audience
- **Software developers** implementing Green IT principles
- **Architects** designing sustainable digital services
- **Code reviewers** assessing environmental and accessibility impact
- **Auditors** conducting compliance checks (RGESN, GR491, Opquast, RGAA)
- **AI assistants** (like Codex, Claude, GitHub Copilot) needing structured guidance
- **Educators** teaching sustainable software development

## Core Frameworks Integrated

### 1. RGESN (Référentiel Général d'Écoconception de Services Numériques)
- **Scope**: Environmental design of digital services
- **Focus**: User needs to infrastructure and lifecycle
- **URL**: https://ecoresponsable.numerique.gouv.fr/publications/referentiel-general-ecoconception/
- **Keywords**: ecoconception, lifecycle, environmental impact, digital services

### 2. GR491
- **Scope**: Responsible digital design decisions
- **Focus**: UX, frontend, backend, data, hosting, governance
- **URL**: https://gr491.isit-europe.org/
- **Keywords**: responsible design, governance, sustainable IT, best practices

### 3. Opquast
- **Scope**: Web quality and reliability
- **Focus**: Understandable, robust web experiences
- **URL**: https://checklists.opquast.com/fr/qualite-numerique/
- **Keywords**: web quality, reliability, user experience, accessibility

### 4. RGAA (Référentiel Général d'Amélioration de l'Accessibilité)
- **Scope**: Digital accessibility
- **Focus**: Keyboard navigation, focus management, semantics, contrast, language
- **URL**: https://accessibilite.numerique.gouv.fr/
- **Keywords**: accessibility, WCAG, inclusive design, assistive technology

## Use Cases

### 1. Code Review
- **Input**: Pull request with code changes
- **Output**: Assessment of environmental and accessibility impact
- **Example**: "This API endpoint fetches too much data; consider pagination for energy savings"

### 2. Architecture Design
- **Input**: System design document
- **Output**: Recommendations for sustainable technology choices
- **Example**: "For this workload, serverless may be more efficient than always-on VMs"

### 3. Compliance Audit
- **Input**: Existing codebase or service
- **Output**: Compliance report against RGESN, GR491, Opquast, RGAA
- **Example**: "The service meets 75% of RGESN criteria; here are the gaps and fixes"

### 4. Development Guidance
- **Input**: Feature specification
- **Output**: Implementation guidance with Green IT considerations
- **Example**: "Use this caching strategy to reduce database queries by 40%"

### 5. AI Model Optimization
- **Input**: LLM or AI model specifications
- **Output**: Recommendations for responsible model usage
- **Example**: "Consider quantizing this model to reduce size without sacrificing accuracy"
